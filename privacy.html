가지런 · GAJI RUN

개인정보처리방침

가지런(이하 '앱')은 러닝 코칭에 꼭 필요한 정보만 받고, 기본으로는 사용자의 폰 안에만 저장합니다. 이 방침은 2026년 11월 5일부터 적용합니다.

1. 처리하는 정보와 목적

구분항목목적
기본 정보(필수)별명, 태어난 해, 성별훈련 기준 계산, 별명 중복 방지
건강 정보(필수, 민감정보)달리는 동안의 심박, 안정·최대 심박, 체중(입력 시), 건강 확인 질문의 답심박 구간과 훈련 강도 계산, 무리한 훈련 경고. 진단·치료에 쓰지 않음
위치 정보달리는 동안의 GPS 위치(경로), 고도거리·페이스 계산, 기록에 경로 표시
운동 기록날짜, 거리, 시간, 페이스, 케이던스, 구간 기록, 목표·훈련 일정코칭, 기록 보관과 통계
계정(선택)구글 계정 이메일, 계정 식별값여러 폰에서 기록 이어 쓰기(클라우드 동기화)
사용 현황기기 종류, 앱 버전, 앱 처음·마지막 사용일, 기록 수·누적 거리, 목표 종류오류 대응, 공지, 서비스 개선 통계
문의'의견 보내기'로 보낸 글, 이메일(적은 경우)답변과 처리

광고 배너는 링크만 보여 주며, 광고를 위해 사용자를 추적하거나 정보를 넘기지 않습니다.

2. 저장 위치와 보유 기간

  • 기본은 사용자의 폰 안에만 저장합니다. 앱을 지우면 함께 사라집니다.
  • 구글 계정으로 로그인하면 Google Firebase(클라우드)에 동기화합니다. 계정을 지울 때까지 보관하고, 지우면 바로 파기합니다.
  • 사용 현황은 마지막 사용일부터 1년이 지나면 자동으로 파기합니다.
  • 문의 글은 받은 날부터 1년이 지나면 자동으로 파기합니다. 요청하면 바로 파기합니다.
  • 파기는 서버와 폰에서 복구할 수 없게 삭제하는 방식으로 합니다.

3. 제3자 제공

개인정보를 제3자에게 제공하지 않습니다. 법령에 따라 수사기관 등이 요구하는 경우만 예외입니다.

4. 처리 위탁과 국외 이전

받는 곳맡기는 일이전 항목·방법
Google LLC (Firebase)데이터 저장, 로그인, 사용 현황 저장1항의 정보 중 클라우드에 올리는 것. 앱을 쓸 때 인터넷으로 암호화해 전송. 서버는 국외에 있을 수 있음

국외 이전을 원하지 않으면 로그인하지 않고 쓰면 됩니다. 이 경우 기록은 폰에만 남고, 별명 예약과 사용 현황만 서버에 저장됩니다.

5. 만 14세 미만

만 14세 미만은 가입할 수 없습니다. 가입할 때 만 14세 이상인지 확인하고, 만 14세 미만이면 만 14세가 된 뒤 가입하도록 안내합니다. 따라서 법정대리인 동의를 받지 않습니다.

6. 사용자의 권리

  • 내 정보 보기·고치기: 앱 설정 › 내 정보 (별명은 바꿀 수 없음)
  • 동의 철회·삭제: 앱 설정 › 고급 › 계정 초기화, 또는 삭제 요청 페이지
  • 처리 정지·열람 요청: 아래 문의처로 요청하면 10일 안에 처리합니다.

7. 안전하게 지키는 방법

  • 클라우드 데이터는 본인 계정으로만 읽고 쓸 수 있게 접근 규칙을 둡니다.
  • 관리자는 지정된 계정만, 매번 구글 로그인을 거쳐 들어갑니다.
  • 모든 전송은 암호화(HTTPS)합니다.

8. 문의처

개인정보에 관한 문의, 열람·정정·삭제·처리 정지 요청은 아래로 보내 주세요. 10일 안에 답하고 처리합니다.

  • 앱 설정 › 의견 보내기
  • 계정·데이터 삭제 요청 페이지 (앱이 없어도 됨)
